# Alicia Upano's Author Website

A clean, responsive portfolio website for author Alicia Upano, built with HTML5 and CSS3.

## 🚀 Quick Start

### Prerequisites
- Git
- A modern web browser
- A code editor (VS Code, Sublime Text, etc.)

### Local Development Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/RoskiDeluge/alicia-upano.git
   cd alicia-upano
   ```

2. **Open the project**
   - Open `index.html` in your browser to view the site
   - Or use a local server for development:
   ```bash
   # Using Python 3
   python -m http.server 8000
   
   # Using Node.js (if you have http-server installed)
   npx http-server
   
   # Using VS Code Live Server extension
   # Right-click index.html → "Open with Live Server"
   ```

3. **View the site**
   - Direct file: Open `index.html` in your browser
   - Local server: Navigate to `http://localhost:8000`

## 🛠️ Development Guidelines

### Making Changes

1. **Create a new branch** for your feature/fix:
   ```bash
   git checkout -b feature/your-feature-name
   # or
   git checkout -b fix/your-bug-fix
   ```

2. **Make your changes** following these guidelines:
   - Keep HTML semantic and accessible
   - Follow the existing CSS structure and naming conventions
   - Test on multiple screen sizes (mobile, tablet, desktop)
   - Ensure cross-browser compatibility

3. **Test your changes**:
   - Check responsiveness on different screen sizes
   - Verify all links and images work
   - Test in major browsers (Chrome, Firefox, Safari, Edge)

### Code Style

- **HTML**: Use semantic elements, proper indentation (2 spaces)
- **CSS**: Follow BEM methodology where possible, use meaningful class names
- **Images**: Optimize for web, include alt text for accessibility
- **Responsive**: Mobile-first approach with appropriate breakpoints

## 📋 Contributing

### For Team Members

1. **Clone the repository** directly:
   ```bash
   git clone https://github.com/RoskiDeluge/alicia-upano.git
   cd alicia-upano
   ```

2. **Create a feature branch**:
   ```bash
   git checkout -b feature/amazing-feature
   # or for bug fixes:
   git checkout -b fix/bug-description
   ```

3. **Make your changes** following the development guidelines above

4. **Commit your changes**:
   ```bash
   git add .
   git commit -m "Add amazing feature: brief description"
   ```

5. **Push your branch**:
   ```bash
   git push origin feature/amazing-feature
   ```

6. **Create a Pull Request** on GitHub for review and approval

### For Designers

If you're a designer wanting to contribute:

1. **Visual changes**: Create mockups or design files and attach them to an issue
2. **Asset updates**: 
   - Images should be optimized for web (WebP preferred, fallback to JPG/PNG)
   - Maintain aspect ratios and provide multiple sizes if needed
3. **Typography/Color changes**: Document the changes clearly in your PR description

### Pull Request Guidelines

- **Clear description**: Explain what changes you made and why
- **Screenshots**: Include before/after screenshots for visual changes
- **Testing**: Mention what browsers/devices you tested on
- **Mobile-friendly**: Ensure your changes work well on mobile devices

## 🐛 Issues
